Ejercicios de JavaScript

Clase 1: Declaraciónes, asignación de valores y variables. Datos primitivos.

Consigna de la Preentrega 01

¿Qué debes construir?

Debes crear un repositorio que contenga un script de JavaScript vinculado a un archivo HTML. El script debe realizar las siguientes acciones:

  1. Solicitar datos: Pedir al menos tres datos distintos al usuario (ej. nombre y año de nacimiento).
  2. Procesar información: Realizar una operación aritmética simple (ej. calcular la edad actual) y una transformación de texto concatenando variables con strings.
  3. Comunicar resultados: Mostrar el resultado final al usuario mediante la colsola o una alerta.

Criterios de Aceptación El proyecto debe cumplir con:

  • Uso de Variables: No utilizar var. Debes usar const para valores que no cambian y let para los que sí.
  • Interacción: Uso correcto de prompt() , parseInt()/parseFloat() para capturar datos y console.log()/alert() para mostrar resultados.
  • Lógica: Realizar al menos una conversión de tipo (recordar que prompt devuelve strings) para realizar un cálculo matemático.
  • Entorno: El script debe estar en un archivo .js externo, dentro de su carpeta, vinculado correctamente al index.htmlen el head con el atributo defer.

Requisitos Técnicos

  1. Estructura de archivos: Crea una carpeta para tu proyecto con un archivo index.html y un archivo main.js en su correspondiente carpeta. Vincula el script en la etiqueta head del HTML con el atributo defer.
  2. Captura de datos: Usa prompt() para solicitarle mínimo tres datos diferentes al usuario. Almacenar los datos en variables o constantes según lo solicitado.
  3. Procesamiento: Conviertelos numeros solicitados vía prompt a tipo number. Concatena strings con la información solicitada al usuario. Realiza operaciones matemáticas con los números solicitados.
  4. Salida de datos: Usa console.log()/alert() para mostrar los diferentes mensajes.
